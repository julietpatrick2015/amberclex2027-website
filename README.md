# AmberClex2027

The complete AmberClex app supplied in `AmberClex2027-website.zip` is hosted as a static website. `public/index.html` is unchanged from the supplied archive.

The site uses HTML, CSS, and browser JavaScript contained in that file. No dependency installation or build step is required. To view it locally, open `public/index.html` in a browser, or serve `public` with a static HTTP server.

Netlify publishes the `public` directory using `netlify.toml`. The requested production address is https://amberclex2027.netlify.app. The API rejected the attempt to rename the existing project as unauthorized; its current address remains https://amberclex2027-website.netlify.app until the rename succeeds.
